Cloudflare Pages + Custom Domain

Hướng Dẫn Triển Khai Web & Tên Miền Riêng

Dùng Cloudflare Pages thay thế cho GitHub Pages giúp web không bao giờ sập, CDN toàn cầu tốc độ cực nhanh, miễn phí 100% SSL & Băng thông.

Mở Cloudflare Dashboard
1

Đẩy mã nguồn lên GitHub

Tạo Repo Public hoặc Private

Bạn tạo 1 repo mới trên GitHub (ví dụ: gauconhihi/my-portfolio) và đẩy toàn bộ thư mục web này lên.

# Các lệnh đẩy lên Git:

git init

git add .

git commit -m "Initial commit"

git remote add origin https://github.com/gauconhihi/my-portfolio.git

git push -u origin main

2

Liên kết Cloudflare Pages

Workers & Pages > Create application

Truy cập dash.cloudflare.com > Vào mục Workers & Pages > Bấm nút Create application > Chọn tab Pages > Connect to Git.

  • Chọn tài khoản GitHub gauconhihi.
  • Chọn repository web vừa tạo.
  • Build command: Để trống (Vì web thuần HTML/JS).
  • Build output directory: / (hoặc để trống).
  • Bấm Save and Deploy.
3

Gắn Tên Miền Riêng (Custom Domain)

Custom Domains tab trong Cloudflare Pages

Sau khi deploy thành công:

  • Trong trang project Pages, chuyển sang tab Custom domains.
  • Bấm Set up a custom domain.
  • Nhập tên miền của bạn (ví dụ: gauconhihi.com hoặc app.gauconhihi.com).
  • Cloudflare sẽ tự động trỏ DNS và cấp phát chứng chỉ SSL/HTTPS miễn phí 100%.
4

Thêm thành viên / Quản trị viên

Cấp quyền tài khoản Cloudflare an toàn

Nếu bạn muốn mời người khác cùng quản lý Cloudflare:

  • Vào Manage Account > Members.
  • Bấm Invite members.
  • Nhập email người cần mời và chọn quyền hạn (ví dụ: Administrator hoặc Cloudflare Pages Admin).
  • Người được mời chấp nhận qua email là xong.

Vì sao Cloudflare Pages tốt hơn GitHub Pages?

⚡ Tốc độ & Ổn định Không bao giờ bị nghẽn mạng do mạng VN chặn, có CDN máy chủ tại Hà Nội & TP.HCM.
🔒 Custom Domain Tự Động Hỗ trợ SSL cực nhanh, DNS Anycast chống DDoS, không sợ chết web khi lượng truy cập lớn.
📁 Unlimited Private Repos Kết nối trực tiếp cả repo riêng tư miễn phí, bảo mật mã nguồn tối đa.

Cấu hình GitHub & Giao diện

Tùy chỉnh tài khoản mặc định và Personal Access Token

Dùng để tải danh sách các Repo và trang GitHub Pages / Cloudflare tương ứng.

Cần thiết để tải lên file vào repo riêng tư (Git Vault Uploader) và tăng giới hạn API rate limit lên 5000 request/giờ.

Các nút "Xem Web" sẽ tự động trỏ đến https://gauconhihi.github.io/<tên-repo>/.

Cấu hình GitHub Token

Mở khóa uploader & truy cập kho lưu trữ

Nhập GitHub Personal Access Token (classic hoặc fine-grained) với quyền repo để cho phép uploader tải file trực tiếp lên kho chứa của bạn.

Bảo mật:

Token chỉ được lưu cục bộ trong LocalStorage trình duyệt của bạn, không bao giờ gửi đến bất kỳ máy chủ bên thứ ba nào.
